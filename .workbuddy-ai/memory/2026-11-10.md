# 2026-11-10

## 整个 web 应用接入 shadcn/ui（保留浅色 STRATA 主题）

- 用户要求「使用 shadcn 里面的 ui 组件替换这个页面的 ui 组件」，确认目标为**整个应用**、方式为**完整接入 + 保留主题**（不是轻量手写、也不是 shadcn 默认灰主题）。
- 基础设施（`apps/web`）：
  - `components.json`（style new-york / Tailwind v4 / cssVariables / lucide / `@/` 别名）；`shadcn` CLI `add` 生成 23 个组件到 `src/components/ui/`。
  - 新依赖：`tailwindcss` + `@tailwindcss/vite` + `tw-animate-css`（dev），`radix-ui`（CLI 安装的统一包）、`cn`（registry 组件用的合并工具）、`class-variance-authority`、`lucide-react`、`clsx`、`tailwind-merge`。
  - `vite.config.ts` 加 `tailwindcss()` 与 `@` 别名；`tsconfig.json` 加 paths；`main.tsx` 在 `styles.css` 之前引入 `src/shadcn.css`。
  - **关键**：`shadcn.css` 只 `@import "tailwindcss/theme.css"` + `utilities.css`（放进 `theme/utilities` layer），**故意不引入 preflight**，否则 Tailwind 的 `margin:0` / `h1 font-size:inherit` / `svg display:block` 会破坏现有布局。Tailwind utilities 在 layer 里、legacy CSS 无 layer，因此 `styles.css` 永远优先，视觉不变。
  - 主题通过 `@theme inline` 把 `--color-*` 全部**别名**到现有令牌（`--bg/--text/--accent/--border/--chart-*` 等），不新增第二套调色板；`--color-accent` → `--accent-dim`（shadcn 的 accent 是 hover 面，不是品牌色）。
- 兼容层（`src/ui.tsx`）：`Button`（shadcn Button + 旧 `button-*` class）、`BareButton`（中和 Button 的 height/gap/padding/nowrap）、`Panel`（shadcn Card + 中和 flex/gap/py/shadow/border/radius）、`SegmentedControl`（shadcn `Toggle`，**不用 ToggleGroup**：Radix single 会渲染 radiogroup/radio，破坏 `role=group` + `aria-pressed` 契约）、`StatePanel`（Panel）、`Notice`（shadcn Alert，`role={undefined}` 保留 `.notice-copy` 的 live region）、`SearchField`（shadcn Input + Label）、`Icon` 改为 lucide-react 并保持 `icon size-4.5` 避免 shadcn Button 把图标压到 16px。
  - `src/components/ui/legacy-badge.tsx`：中和 Badge 自身几何，避免给原本无样式的 `.badge` 加胶囊边框。
  - 原生 `<select>` 用 shadcn `NativeSelect`（不是 Radix Select），保留 `.selectOption()`/`<option>`；`<details>/<summary>`、图表 tooltip、`role="meter"`、原生 checkbox 均保持原生，因 e2e/UX-CONTRACT 强依赖。
  - 三张表用 shadcn `TableHeader/Body/Row/Head/Cell` 但保留原生 `<table>` 与滚动容器；`shadcn.css` 加规则中和 shadcn 的 `border-b` / `h-10` / `whitespace-nowrap`。
- 页面：App 外壳（nav `Button asChild`、状态 Badge、rail `Panel`、TooltipProvider）、Overview/Session/Hardware 全部页面的卡片、徽标、按钮、输入、表格、标签页均已替换；共 21 个既有文件改动 + 新增 24 个 shadcn 文件。
- 验证：`tsc --noEmit` / `vite build` / web 174 单测 / engine 224 单测 / 16 项令牌漂移 / `git diff --check` 全通过。
- e2e（系统 Chrome，因本机无 Playwright 浏览器下载，临时 config 指向 `/Applications/Google Chrome.app/...`，跑完已删）：HEAD 干净 worktree 基线 62 passed / 9 failed；改动后 62 passed / 10 failed（多出 1 项 `hardware energy follows its range` 在 HEAD 单独跑也失败，属演示数据时间抖动）。最终一轮因 flake 出现 11 failed / 61 passed，新增的 `failed lists and missing sessions` 单独重跑通过。**无新增确定性回归**。
- 前后截图对比（`before-*`/`after-*`）确认浅色 STRATA 视觉一致；期间修掉两处样式偏差：shadcn Card 给无边框的性能卡加边框、shadcn Badge 给纯文本徽标加胶囊。
